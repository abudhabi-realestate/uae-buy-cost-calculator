# 阿联酋买房总成本计算器

离线静态页，支持**期房**与**二手现房**费用估算；期房含付款计划与 Excel 导出。

**在线访问：** https://abudhabi-realestate.github.io/uae-buy-cost-calculator/

## 功能

- **期房**：迪拜 DLD / 阿布扎比 ADREC 登记费、付款计划、导出 Excel（不含交房 Title Deed 阶段费用展示）
- **二手现房**：过户登记、Trustee、经纪佣金、NOC、按揭相关费用
- 酋长国：迪拜（DLD 常见 4%）/ 阿布扎比（ADREC 常见 2%）
- 可选按揭：LTV、年利率、年限、等额本息利息估算

## 免责声明

估算仅供参考；实际费用以 SPA、DLD / ADREC、银行及合同约定为准。
